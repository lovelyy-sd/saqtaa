Вход

Введите пароль, чтобы создавать приглашения.

0. Продолжить старое

1. Шаблон и язык

Выбор сохраняет оригинальный дизайн шаблона. Примерные тексты можно заменить ниже.

2. Главное

Время по Казахстану (UTC+5). Окончание нужно для календаря гостя. Ссылка перестаёт открываться после конца дня мероприятия.

3. Место

Если пусто — откроется поиск 2ГИС по адресу. Точная ссылка лучше: в 2ГИС откройте место → «Поделиться» → скопировать.

4. Тексты

В тексте и подписи можно писать {names} — подставятся имена с обложки. Если выбран язык «Оба», у каждого языка своё отдельное поле: казахский текст не переводится сам, его нужно вписать (или попросить перевод в чате с Claude и вставить сюда).

5. Программа дня

Время общее, названия и описания — отдельно для каждого языка.

6. Фото и подтверждение присутствия

Фото сохраняется в браузере для черновика и предпросмотра. Для публичной ссылки вставьте HTTPS-ссылку на фото ниже.

Если фото не добавлено, приглашение останется без фотографии.

Инструкция для Google Таблицы (за 1 минуту):
1. Создайте пустую Google Таблицу на sheets.new.
2. В меню нажмите «Расширения» → «Apps Script», сотрите весь текст и нажмите кнопку «Скопировать готовый код» выше.
3. Нажмите синюю кнопку «Развернуть» → «Новое развертывание» → шестеренка слева «Тип: Веб-приложение» → У кого есть доступ: «Все» (Anyone) → нажмите «Развернуть».
4. Скопируйте полученную ссылку на веб-приложение и вставьте её сюда.
✦ Клиенту можно будет отправить готовую ссылку онлайн-статистики, которая сама обновляется при каждом ответе гостя!

Ключ создаётся на web3forms.com на почту клиента. Ответы гостей будут приходить письмами на указанную почту.

7. Готово

Заполнится автоматически. При необходимости укажите адрес страницы приглашения.

Сокращатель is.gd увидит содержимое ссылки. Проверьте короткую ссылку перед отправкой.

Созданные приглашения сохраняются на этом устройстве. Поиск по названию мероприятия, дате или времени.

9. Резервная копия

Сохраните все черновики, историю и локальные фотографии в один JSON-файл. На другом устройстве откройте админ-панель и импортируйте этот файл. Автоматической синхронизации между устройствами нет.

Рекомендуется делать копию после каждого важного заказа.
