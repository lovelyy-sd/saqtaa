Мои приглашения

Редактор приглашения

Это название видно только вам в списке заказов.

1. Шаблон и язык

При смене шаблона подставятся примерные тексты — потом их можно править.

2. Главное

Время по Казахстану (Asia/Almaty, UTC+5). Окончание нужно для календаря гостя.

3. Место

Если пусто — откроется поиск 2ГИС по адресу. Точная ссылка лучше: в 2ГИС откройте место → «Поделиться» → скопировать.

4. Тексты

В тексте и подписи можно писать {names} — подставятся имена с обложки. Если выбран язык «Оба», казахский текст нужно вписать отдельно.

5. Программа дня

Время общее, названия и описания — отдельно для каждого языка.

6. Фото и почта

Прямая ссылка на картинку (например, из папки img/ на GitHub Pages). Если пусто — шаблон без фото.
Получить: web3forms.com → указать почту клиента → ключ придёт на неё. Без ключа ответы никуда не уйдут.

Готово

Заполнится само. Если страница лежит в другом месте — поправьте один раз, запомнится.
Открыть короткую

Сокращатель — сторонний сервис is.gd: он увидит содержимое ссылки (имена, дату, место). Проверьте короткую ссылку перед отправкой.
