# SAQTAA

Сервис цифровых приглашений на той, свадьбу, юбилей, день рождения и тұсау кесер. Работает статически на GitHub Pages в связке с облачным бэкендом на Google Apps Script.

## Структура проекта

- `index.html` — витрина (лендинг) с интерактивным демо-просмотром всех 6 шаблонов (`Luxury`, `Floral`, `Qazaq`, `Editorial`, `Emerald`, `Tusau`) на русском и казахском языках (`RU / ҚАЗ`), переключением режима «С фото / Без фото» и живым счётчиком ответов гостей.
- `admin.html` — мобильная и десктопная панель администратора (5 вкладок: Главная, Заказы, Конструктор, Статистика, Настройки). Поддерживает:
  - выбор шаблона, языка (`Русский`, `Қазақша`, `Оба`), настройку дресс-кода (по шаблону / свой / скрыть) и программы вечера;
  - сжатие и загрузку фотографий напрямую на Google Диск SAQTAA;
  - облачную синхронизацию заказов и резервное копирование (`.json`);
  - генерацию клиентской ссылки приглашения (`invite.html#z...`) и ссылки живой статистики (`stats.html#z...`).
- `invite.html` — страница клиентского приглашения (читает сжатые `deflate-raw` данные из `#z...` / `#j...` фрагмента ссылки, отображает таймер обратного отсчёта, карту 2ГИС, карточку дресс-кода с 3D-жемчужинами оттенков, форму RSVP с выбором числа гостей `1–10` и сводку ответов).
- `stats.html` — клиентская страница онлайн-статистики ответов гостей в реальном времени (фильтрация по статусу, поиск, ручное добавление гостей `1–10 чел.`, выгрузка в Excel/CSV и готовый текстовый отчёт для WhatsApp на русском и казахском языках).
- `server.gs` — единый серверный скрипт Google Apps Script (авторизация админ-панели, загрузка фото на Google Диск, хранение заказов и ответов гостей в Google Таблице `ORDERS` / `RSVPS`, автоматическая отправка HTML-уведомлений клиенту через `GmailApp`).
- `og-image.jpg` — изображение предпросмотра ссылки для WhatsApp, Telegram и соцсетей.

## Публикация на GitHub Pages

1. Загрузите файлы репозитория в ветку `main`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
4. Нажмите **Save** и дождитесь публикации.

## Подключение облачного сервера (`server.gs`)

1. Создайте новую Google Таблицу и откройте **Расширения → Apps Script**.
2. Вставьте код из `server.gs` (или нажмите **«📋 Код скрипта»** в разделе **Настройки → Ссылки и домен** внутри `admin.html`).
3. Нажмите **Начать развертывание → Новое развертывание → Веб-приложение**:
   - Запуск от имени: **Меня**
   - У кого есть доступ: **Все**
4. Скопируйте полученный URL `https://script.google.com/macros/s/.../exec` и вставьте его в `admin.html` (**Настройки → Ссылки и домен → Проверить**).
5. При необходимости смените стандартный пароль администратора в разделе **Настройки → Профиль и пароль**.
