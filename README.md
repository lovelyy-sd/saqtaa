# SAQTAA

Сервис цифровых приглашений на той, свадьбу, қыз ұзату, тұсау кесер, юбилей, день рождения, сүндет той и шілдехана. Работает статически на GitHub Pages в связке с защищённым облачным бэкендом на Google Apps Script.

## Структура проекта

- `index.html` — витрина (лендинг) с интерактивным демо-просмотром **12 универсальных шаблонов** (`Luxury`, `Floral`, `Qazaq`, `Editorial`, `Emerald`, `Sun Cream`, `Silk`, `Алтын Ұя`, `Ақ жол`, `Pearl`, `Lavender`, `Sunset`), адаптацией под 8 видов мероприятий с умными рекомендациями, переключением языка (`RU / ҚАЗ`), режима «С фото / Без фото» и живым счётчиком ответов.
- `admin.html` — мобильная и десктопная панель администратора (5 вкладок: Главная, Заказы, Конструктор, Статистика, Настройки). Поддерживает:
  - выбор вида мероприятия (8 пресетов RU/KZ) и любого из 12 стилей оформления;
  - выбор языка (`Русский`, `Қазақша`, `Оба`), настройку дресс-кода (по шаблону / свой / скрыть) и программы вечера;
  - сжатие и загрузку фотографий напрямую на Google Диск SAQTAA;
  - облачную синхронизацию заказов и резервное копирование (`.json`);
  - генерацию раздельных ссылок: публичной ссылки приглашения (`invite.html#z...` — без почты клиента и без токена статистики) и приватной ссылки статистики для заказчика (`stats.html#z...` с секретным токеном `st`).
- `invite.html` — страница клиентского приглашения (читает сжатые `deflate-raw` данные из `#z...` / `#j...` фрагмента ссылки, отображает таймер обратного отсчёта, карту 2ГИС, карточку дресс-кода с 3D-жемчужинами оттенков, форму RSVP с выбором числа гостей `1–10` и агрегированные счётчики ответов без раскрытия имён гостей).
- `stats.html` — защищённая клиентская страница онлайн-статистики ответов гостей в реальном времени (доступ к списку гостей только по токену `st` через `POST`, фильтрация по статусу, поиск, ручное добавление гостей `1–10 чел.`, выгрузка в Excel/CSV и готовый текстовый отчёт для WhatsApp на русском и казахском языках).
- `server.gs` — единый защищённый серверный скрипт Google Apps Script v4.0:
  - серверная авторизация по свойству `ADMIN_PIN` из Script Properties (все защищённые вызовы принимаются строго по `POST`);
  - загрузка фото на Google Диск с проверкой типа и размера файла;
  - хранение заказов и ответов гостей в Google Таблице `ORDERS` / `RSVPS` с защитой от формульных инъекций и ограничением числа гостей `1–10`;
  - автоматическая отправка экранированных HTML-уведомлений через `GmailApp` только на подтверждённый Email из таблицы `ORDERS`;
  - раздельные эндпоинты: публичные счётчики (`action=counts`) и защищённый список гостей (`action=stats` по токену `st` или `ADMIN_PIN`).
- `og-image.jpg` — изображение предпросмотра ссылки для WhatsApp, Telegram и соцсетей (`1200×630`).

## Публикация на GitHub Pages

1. Загрузите файлы репозитория в ветку `main`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
4. Нажмите **Save** и дождитесь публикации.

## Подключение облачного сервера (`server.gs`)

1. Создайте новую Google Таблицу и откройте **Расширения → Apps Script**.
2. Вставьте код из `server.gs` (или нажмите **«📋 Код скрипта»** в разделе **Настройки → Ссылки и домен** внутри `admin.html`).
3. **Обязательно задайте пароль администратора:** откройте **Настройки проекта (шестерёнка слева) → Свойства скрипта → Добавить свойство**:
   - Свойство: `ADMIN_PIN`
   - Значение: ваш надёжный пароль (от 4 символов)
4. Нажмите **Начать развертывание → Новое развертывание → Веб-приложение** (при обновлении кода используйте **Управление развертываниями → Редактировать → Новая версия**):
   - Запуск от имени: **Меня**
   - У кого есть доступ: **Все**
5. Скопируйте полученный URL `https://script.google.com/macros/s/.../exec`, откройте `admin.html`, войдите с вашим `ADMIN_PIN` и проверьте подключение в **Настройки → Ссылки и домен → Проверить**.
