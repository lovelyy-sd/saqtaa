# SAQTAA

Статический сайт цифровых приглашений. Подготовлен для публикации через GitHub Pages.

## Публикация

1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Нажмите **Save** и дождитесь публикации. Адрес сайта появится в разделе Pages.

## Обязательные настройки перед запуском

Откройте `index.html` и найдите блок `const CONFIG`:

- `WA_NUMBER` — замените `77000000000` на свой номер WhatsApp в международном формате, без `+`.
- `EVENT_DATE`, `EVENT_TIME`, `EVENT_END_TIME` — дата и время демонстрационного события.
- `EVENT_TZ` — часовой пояс события.

### Ответы RSVP

Сейчас `RSVP_CONFIG.mode` установлен в `demo`. В этом режиме форма показывает подтверждение, но ответы организатору не отправляет.

Чтобы получать ответы на почту:
1. Создайте ключ на Web3Forms.
2. Установите `mode: "web3forms"`.
3. Вставьте ключ в `web3formsKey`.

Не вставляйте Telegram bot token в публичный HTML: его сможет увидеть любой посетитель сайта. Для Telegram используйте серверный прокси или backend.

## Важно

- Сайт состоит из одного файла `index.html`; отдельные папки со стилями и скриптами не требуются.
- Шрифты загружаются из Google Fonts; при отсутствии интернета будут использованы системные запасные шрифты.
- Перед коммерческим запуском замените демонстрационные имена, даты, адреса и данные площадок внутри конфигурации/демо-шаблонов.
- Проверьте все кнопки WhatsApp и отправку RSVP после публикации.
