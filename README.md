# SAQTAA

Статический сервис цифровых приглашений. Подготовлен для публикации через GitHub Pages.

## Структура проекта

- `index.html` — витрина (лендинг) с демонстрацией 6 шаблонов приглашений на русском и казахском языках.
- `admin.html` — конструктор приглашений (создание и редактирование ссылок, живой предпросмотр, локальная история и резервные копии).
- `invite.html` — страница клиентского приглашения (читает сжатые данные из `#`-фрагмента ссылки, формирует `.ics` календарь и отправляет ответы гостей через Web3Forms).
- `og-image.jpg` — изображение предпросмотра для мессенджеров и соцсетей.

## Публикация на GitHub Pages

1. Загрузите файлы репозитория в ветку `main`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
4. Нажмите **Save** и дождитесь публикации.

## Настройка витрины (`index.html`)

Откройте `index.html` и найдите блок `const CONFIG`:

- `WA_NUMBER` — номер WhatsApp для приёма заказов в международном формате без `+` (например, `77788613881`).
- `PRICE` — стоимость приглашения в тенге.
- `TZ` и `TZ_OFFSET` — часовой пояс событий (`Asia/Almaty`, `+05:00`).
- `RSVP_DAYS` — за сколько дней до события просить подтвердить присутствие.
- `EVENTS` — демонстрационные даты и время для карточек шаблонов № 01 — № 06.

## Создание клиентских приглашений (`admin.html` и `invite.html`)

1. Откройте `admin.html`, выберите шаблон, язык (`Русский`, `Қазақша` или `Оба`), заполните имена, дату, время, адрес и программу дня.
2. **Ответы гостей (RSVP):**
   - В демо-режиме на витрине `index.html` форма показывает подтверждение, но ответы никуда не отправляет.
   - Для реального приглашения в `admin.html` создайте ключ на [Web3Forms](https://web3forms.com/) на почту клиента и укажите его в поле «Ключ Web3Forms клиента» (или отключите RSVP).
3. Нажмите **«Создать ссылку»** — сгенерируется ссылка вида `https://<ваш-домен>/invite.html#z...`, готовую к отправке гостям.

> Не вставляйте секретные серверные токены (например, Telegram Bot Token) в публичный HTML-код: статические файлы доступны любому посетителю.
