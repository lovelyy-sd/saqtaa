# SAQTAA — стартовый каталог приглашений

Статический проект на HTML, CSS и обычном JavaScript. Не требует установки библиотек.

## Запуск
1. Распакуйте архив.
2. Откройте папку в Visual Studio Code.
3. Откройте `index.html` в браузере. Для удобства можно использовать расширение Live Server.

## Что уже есть
- Главная страница каталога с пятью визуальными направлениями: Luxury, Floral, Qazaq, Editorial, Emerald.
- Переключатель русского и казахского языка в каталоге.
- Пять направлений с разными поводами и композициями: Luxury, Floral и Qazaq — свадьба; Editorial — юбилей; Emerald — день рождения.
- У каждого направления своё фото и расположение элементов: классическая обложка Luxury, арка Floral, орнаментальная панель Qazaq, журнальный блок Editorial и арочная фото-рамка Emerald.
- Для быстрой загрузки каталога используются лёгкие превью, а в демонстрационных карточках — отдельные версии фотографий высокого разрешения.
- В каталоге описаны основные возможности приглашения: обратный отсчёт, место в 2ГИС и подтверждение присутствия.
- Язык сохраняется в ссылке при переходе между каталогом и демо; RSVP требует отдельного выбора ответа и подтверждения.
- В демо каждого дизайна есть фото- и текстовая обложка, переключение русского/казахского и временная замена фотографии.
- На всех демо адаптивная мобильная вёрстка; персональные дата, место, ссылка 2ГИС и сбор ответов подключаются при изготовлении готового приглашения.
- Адаптивная вёрстка для телефона и компьютера.
- Плавное появление блоков при прокрутке с учётом системной настройки уменьшения анимации.
- Финальная карточка SAQTAA внизу страницы по предоставленному референсу.
- Кнопки заказа через WhatsApp с заранее подготовленным сообщением.
- Демонстрационный RSVP-блок с отдельными полями имени и фамилии и тремя вариантами ответа.
- Кнопка 2ГИС показана как часть дизайна; точная ссылка на ресторан задаётся для готовой пригласительной карточки.
- Музыки нет.

## Стили
- `css/polish.css` подключается последним и содержит все финальные правки вёрстки (сетка каталога, мобильная версия, обложки демо, RSVP). Исправляя внешний вид, начинайте с него.

## Что нужно настроить
1. Откройте `js/config.js`.
2. Замените `YOUR_WHATSAPP_NUMBER` на свой номер WhatsApp в формате `77001234567`.
3. Укажите `eventTitle`, дату в `eventDate` формате `YYYY-MM-DD` и время в `eventTime`; дата приглашения и счётчик дней, часов, минут и секунд обновятся автоматически.
4. Для свадебных приглашений укажите имена в `brideName` и `groomName`; если оставить их пустыми, появятся нейтральные подписи на выбранном языке.
5. Заполните `venue`, `address` и `city`; чтобы вести гостей прямо на карточку ресторана, вставьте ссылку из 2ГИС («Ссылка на это место») в `twoGisUrl`.
6. Для индивидуальных фото замените соответствующую пару файлов в `images/optimized`: `*-card.jpg` используется в каталоге, `*-hero.jpg` — в демо (например, `floral-card.jpg` и `floral-hero.jpg`). Загрузку в демонстрационном предпросмотре можно использовать для временной проверки снимка; она действует только в текущей вкладке.
7. Чтобы получать RSVP-ответы, создайте форму в Formspree и вставьте её endpoint в `formspreeEndpoint`.
8. Настройте номер WhatsApp для заказа. Для публикации каталога используйте вымышленные данные и изображения с разрешением на публикацию.

## Важно
В каталоге три свадебных дизайна (Luxury, Floral и Qazaq), Editorial предназначен для юбилея, а Emerald — для дня рождения. В каждом демо используются отдельные подписи и фотографии по случаю; фото можно заменить для предпросмотра в текущей вкладке. RSVP не отправляет данные, пока не указан Formspree endpoint. Не размещайте конфиденциальные данные клиентов в публичном каталоге. GitHub Pages публикует файлы и конфиги по URL.
